# M6: 도감 · 업적 · 칭호 · 통계 · 자동강화 · 설정 구현 계획

**Goal:** 스펙의 기능을 전부 채운다. 남는 것은 튜닝과 출시 준비(M7)뿐이다.

**Architecture:** 진행도(`ProgressState`)는 M1에서 이미 완성되어 있다. M6는 그것을 **보여 주는**
화면 넷과, 규칙이 이미 `:core`에 있는 자동강화를 배선하는 일이다. 설정은 모드와 무관한
전역 값이라 `SaveStore`에 별도 파일로 둔다.

## Global Constraints

M1~M5의 제약이 유효하다. 여기에 더해:

- **업적·통계 규칙을 화면에 다시 쓰지 않는다.** `Progress`·`Achievement`에서 읽는다.
- **자동강화는 `ForgeEngine.canAutoForge`가 허락하는 동안만 돈다.** 화면이 단계를 비교하지 않는다.
- 브랜치 `m6-codex-stats-auto`.

---

### Task 1: 설정 저장과 자동강화

- `:core`에 `Settings(autoPrevent: Boolean)` 추가, `SaveStore.loadSettings/saveSettings`
- ViewModel: `startAutoForge(target)` / `stopAutoForge()`, `setAutoPrevent(on)`
- 자동강화는 안전구간을 벗어나거나 골드가 부족하면 스스로 멈춘다
- 방지권 자동사용이 켜져 있으면 파괴 창을 열지 않고 즉시 되살린다
- 테스트: 경계에서 멈추는지, 자동사용이 창을 건너뛰는지, 설정이 저장되는지

### Task 2: 도감 화면

88칸 격자. 획득한 칸은 실제 검 그림, 못 얻은 칸은 어두운 실루엣.
칸마다 어느 난이도에서 얻었는지 뱃지.

### Task 3: 업적·칭호 화면

`Achievement.entries`를 훑어 달성 여부를 보여 주고, 달성한 것 중 하나를 칭호로 고른다.

### Task 4: 통계 화면

핵심은 **표기 확률 대 실제 확률 비교표**. 단계별로 나란히 놓는다.
그 아래 누적 수치(시도·성공·파괴·연속 실패·골드·조각·방지권·줍기).

### Task 5: 설정 화면과 마무리

방지권 자동사용 토글, 라이선스 고지, 앱 정보.
효과음 토글은 넣지 않는다 — 아직 소리가 없다. 없는 기능의 스위치를 두지 않는다.

전체 검증, README v0.7.0, main 병합·푸시.
