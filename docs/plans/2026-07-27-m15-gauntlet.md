# M15 무한 회랑 로그라이트 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) 문법.

**Goal:** 독립 로그라이트 모드 — 층 웨이브 + 갈림길 3택 + 5층 보스 체크포인트 + 시간초과 페널티(미확정 보상 70%). 10층 최초 클리어 = 허검, 25층 = 회랑의 정령 알.

**Architecture:** 런 상태·판정 전부 `:core` `GauntletEngine` 순수 함수(GauntletRun 불변 데이터). ViewModel 은 시계와 탭만. 화면은 사냥 부품(MonsterSprite·팝업) 재사용.

## Global Constraints

- M11~M14 전부 그대로. 회랑에서 검은 절대 부서지지 않는다
- 해금: **화산 보스 처치**(`clearedZoneIds`에 volcano). 영구 저장은 `gauntletBest` 하나 —
  파워는 본편에서 오고, 회랑은 기록과 해금만 남긴다

### Task 1: GauntletEngine (TDD)

`core/.../Gauntlet.kt` + `GauntletTest.kt`:

```kotlin
enum class GauntletBuff(label, blurb) { ATTACK(+20% 피해), TIME(층 시간 +3초), GOLD(보상 +50%), CRIT(치명타 +5%p) }
sealed interface GauntletChoice { Blessing(buff); Treasure(gold, shards); Cursed }
data class GauntletRun(
    floor=1, killsInFloor=0, timeLeftMillis, monsterHp, monsterMaxHp, isBossFloor,
    cursed=false, pendingGold=0L, pendingShards=0, bankedGold=0L, bankedShards=0,
    buffs: Set<GauntletBuff> = emptySet(), choosing=false, choices=emptyList(), over=false)
object GauntletEngine {
    WAVE_SIZE=5; FLOOR_SECONDS=25; BOSS_EVERY=5; HP_GROWTH=1.35; BASE_HP=60.0; BASE_GOLD=40.0
    LOSS_RATIO=0.7; VOID_FLOOR=10; WISP_FLOOR=25
    ATTACK_BUFF=1.2; TIME_BUFF_MILLIS=3000L; GOLD_BUFF=1.5; CRIT_BUFF=0.05
    fun start(): GauntletRun
    fun monsterHp(floor, isBossFloor, cursed): Long   // BASE_HP*1.35^(floor-1) ×(보스 6배)(저주 2배)
    fun killReward(floor, isBossFloor, cursed, buffs): Pair<Long,Int>  // 저주 4배·GOLD 버프
    fun damage(run, hit: Long): GauntletRun  // ATTACK 버프 적용, 처치·웨이브 완료·보스 뱅킹까지
    fun rollChoices(rng): List<GauntletChoice>  // 축복(무작위 버프)·보물(층 비례)·저주 셋
    fun choose(run, index): GauntletRun          // 다음 층 시작
    fun tick(run, millis): GauntletRun           // 시간 소진 → over=true
    fun payout(run): Pair<Long,Int>              // banked + pending×0.7 (over 여부 무관 수식)
}
```
- [ ] 테스트: 층 체력 증가·보스 6배·저주 2배 / 5킬 → choosing / 보스 층은 1마리 /
  보스 클리어 → pending 이 banked 로 / 버프 적용(공격·시간·골드) / 시간초과 → over /
  payout = banked + pending×0.7 / choose 가 다음 층을 연다
