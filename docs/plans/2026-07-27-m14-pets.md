# M14 펫 10종 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 구역 테마 펫 10종 — 보스 알 드롭(5%)·수상한 알(20%)로 수집, 중복 = 레벨(1~5), 장착 1마리가 사냥에 보너스를 준다.

**Architecture:** 효과 수식은 `:core` `Pets` 순수 함수(장착 펫 기준). 알 상태는 `GameState.pets`(기본값, 세이브 호환). 스프라이트는 monster_sheet 40~49칸에 10칸 추가(시트 재생성).

## Global Constraints

- M11~M13 계획의 Global Constraints 전부 그대로
- 난수 소비 순서 추가 계약: 보스 처치 = 기존(드롭) 뒤에 **알 판정 nextDouble**,
  수상한 알 처치 = 조각 대신 **알 판정 nextDouble** 을 먼저
- 알은 플레이로만 나온다(가챠·과금 없음). 주간 퀘스트 보상은 "지금 사냥 구역"의 알

    QUOKKA(초원 쿼카·meadow·자동 타격), SPRIGGAN(숲 요정·forest·골드+),
    SPIDERLING(꼬마 거미·cave·이벤트 확률+), GOLEMLING(꼬마 골렘·mine·조각+),

    SHADOW_IMP(그림자 임프·abyss·희귀 확률+), HALL_WISP(회랑의 정령·endless_hall·회랑 보상+, M15 배선)

@Serializable data class PetState(counts: Map<String,Int> = emptyMap(), equippedId: String? = null)
object Pets {
    const val MAX_LEVEL = 5; const val EGG_DROP_CHANCE = 0.05; const val EGG_EVENT_CHANCE = 0.20
    fun byZone(zoneId): PetKind?
    fun levelOf(state, id): Int  // counts.coerceAtMost(5)
    fun addEgg(state, id): PetState
    fun equip(state, id?): PetState  // 소유한 펫만

    fun bossTimeBonusMillis(state): Long // 꼬마 백곰 1000~3000
    fun rareBonusOf(state): Double       // 그림자 임프 +0.02~0.06
    fun gauntletMultOf(state): Double    // 회랑의 정령 1.10~1.30 (M15)

### Task 3: ViewModel 배선

- `GameState.pets: PetState = PetState()` (Task 1에서)
