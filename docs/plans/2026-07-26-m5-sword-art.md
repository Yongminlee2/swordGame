# M5: 검 아트 88종 구현 계획

**Goal:** 계열 8종 × 티어 11종 = 88가지 검이 서로 구분되게 보인다.

**Architecture:** 통 이미지 88장을 그리지 않는다. **계열이 형태를, 티어가 색과 장식을 정하는**
두 축의 파라미터로 두고 Compose `Canvas`에서 조립한다. 그림 파일이 0개라 APK가 커지지 않고,
톤이 저절로 일관되며, 계열이나 티어를 추가할 때 파라미터 한 줄만 늘리면 된다.

**참조:** [스펙](../specs/2026-07-26-sword-enhance-game-design.md)

## Global Constraints

- **검을 그리는 지식은 `ui/SwordArt.kt` 한 곳에만 둔다.** 나중에 CC0 스프라이트로 갈아 끼우게 되면
  이 파일만 바꾸면 되도록.
- 저작권 방침 유지: 타사 게임 리소스를 쓰지 않고, 판타지 무기의 일반적 표현 관습만 사용한다.
- 브랜치 `m5-sword-art`.

---

### Task 1: 계열별 날 형태

`BladeSpec` — 계열이 정하는 것.

| 계열 | 형태 |
|---|---|
| 직검 | 곧은 양날, 표준 폭 |
| 곡도 | 한쪽날, 바깥으로 휜 곡선 |
| 대검 | 아주 넓고 긴 양날 |
| 세검 | 바늘처럼 가늘고 긴 날 |
| 쌍검 | 짧은 날 두 자루가 X 로 겹침 |
| 마검 | 날 양옆에 가시가 돋음 |
| 성검 | 날 가운데 홈, 넓은 십자 코등이 |
| 용검 | 물결치는 곡선날에 비늘 |

### Task 2: 티어별 색과 장식

`TierStyle` — 티어가 정하는 것: 날 색, 날끝 하이라이트, 코등이 색, 보석 색, 오라 세기.
+15 이상은 오라가 붙고, 무한 전용 티어 3종은 더 강하게.

### Task 3: 조립과 화면 연결

`DrawScope.drawSword(family, tier, level)` 로 오라 → 날 → 코등이 → 손잡이 → 보석 순서로 겹친다.
`SwordView` 는 이 함수를 부르기만 한다. 강화 화면에 티어 이름을 표시한다
(검의 이름은 계열이 아니라 티어다 — "+13 화염검", 그 아래 "직검 계열").
