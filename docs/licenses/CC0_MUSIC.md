# CC0 배경음 출처

두 음원은 OpenGameArt 원본 페이지에서 CC0로 공개된 파일을 이름만 Android 리소스 규칙에
맞춰 저장했다. CC0는 표기 의무가 없지만 원작자와 원본 파일을 다시 찾을 수 있도록 기록한다.
