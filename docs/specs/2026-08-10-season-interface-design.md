# 시즌별 픽셀 대장간 인터페이스 설계

## 목표

- 선택한 1번 시안의 정보 구조와 화면 비율을 실제 게임 화면에 그대로 옮긴다.
- 전체 화면 안에서 강화가 끝나도록 하고 세로 스크롤을 만들지 않는다.
- 2D B급 게임 감성에 맞춰 모든 기능 아이콘을 16비트 픽셀 자산으로 통일한다.
- 검 스프라이트와 강화 규칙은 바꾸지 않는다.
- 상점, 조합, 가방, 단련, 도감과 기록의 하위 화면까지 같은 디자인 언어를 사용한다.

## 시각 체계

검은색에 가까운 대장간 배경 위에 얇은 직선과 잘린 모서리 패널을 놓는다. 둥근 카드,
큰 그림자, 반투명 유리 효과는 사용하지 않는다. 제목과 핵심 수치는 굵고 밝게, 설명은
회색으로 낮춰 한눈에 우선순위가 보이게 한다. 강화 버튼만 호박색 면으로 강하게 채운다.

아이콘은 16비트 픽셀 스타일, 검은 외곽선, 두세 단계 명암을 공통 규칙으로 사용한다.
골드·조각·강화석·방지권·기록·확률·비용·소모품·다섯 메뉴와 하위 화면 아이콘까지 같은
자산군을 사용하며 문자 기호나 이모지로 대신하지 않는다.

| 구분 | 시즌1 | 시즌2 |
|---|---|---|
| 강조색 | 황동·호박색 | 청록·시안색 |
| 배경 | 따뜻한 불빛과 주황 불티 | 차가운 심층 조명과 주황 불티 |
| 재화 | 골드·조각·방지권 | 골드·조각·강화석·방지권 |
| 주요 기능 | 강화와 기본 메뉴 | 강화석, 사냥터와 심층 콘텐츠 추가 |
| 기록 메뉴 | 기본 기록만 노출 | 펫 등 해금된 심층 기록 노출 |

시즌 판정은 현재 장착한 검이 아니라 `Unlocks.deepUnlocked`를 따른다. 한 번 용검을 얻은
뒤에는 다른 검을 들어도 시즌2 표현과 기능이 유지된다.

## 화면 규칙

### 대장간

화면 순서는 제목과 시즌, 최고 기록, 재화, 검, 이름과 단계, 계열 효과, 결과 확률, 비용과
판매가, 소모품, 강화 버튼, 시즌2 동작, 하단 다섯 메뉴로 고정한다. 확률은 성공·유지·하락·
파괴를 같은 폭의 열로 나누고 얇은 세로선으로 구분한다. 앱은 시스템 바를 숨긴 몰입형 전체
화면을 사용하며 두 시즌 모두 1080×2340 안에서 스크롤 없이 조작 가능해야 한다.

시즌2에서만 강화석 요구량과 사냥터 진입을 강화 버튼 아래 한 줄에 표시한다. 시즌1에서는
그 줄 자체를 없애 남은 공간을 검과 확률 영역에 사용한다.

### 기본 메뉴와 하위 화면

상점·조합·가방·단련·도감은 하단의 이어진 다섯 칸 메뉴를 사용한다. 선택한 메뉴는 시즌
강조색과 얇은 상단선으로 표시한다. 내부 화면은 공통 뒤로 가기, 제목, 시즌 표식, 재화 줄,
잘린 모서리 패널과 픽셀 아이콘을 공유한다. 기록·도움말·설정·사냥터·시련 화면도 같은
규칙을 따른다.

### 시즌 전용 노출

- 시즌1에는 강화석과 사냥터 진입을 표시하지 않는다.
- 시즌1 기록 메뉴에는 펫처럼 아직 획득할 수 없는 항목을 표시하지 않는다.
- 시즌1 보관함의 빈 상태는 사냥터 이용을 전제로 안내하지 않는다.
- 시즌2에는 실제 해금된 심층 기능만 추가하고 시즌1의 기본 흐름은 그대로 둔다.

## 리소스와 구현

- 계절별 배경은 `drawable-nodpi`에서 원본 비율을 유지해 화면을 채운다.
- `ui_pixel_*.png` 30개가 재화, 상태, 메뉴와 하위 화면 아이콘을 담당한다.
- 픽셀 아이콘은 보간 없이 그려 가장자리가 흐려지지 않게 한다.
- `ForgeSeasonTheme`가 시즌별 색 체계를 선택한다.
- `ForgeBackdrop`, `ForgePanel`, `PixelActionButton`, `ScreenHeader`, `WalletBar`가 공통 구조를 담당한다.
- 모든 기존 검 이미지는 원본 리소스를 그대로 사용한다.

## 검증 기준

- `SM_A165N` 1080×2340, 450 dpi 실기기에서 확인한다.
- 시즌1과 시즌2 대장간에서 하단 메뉴가 잘리지 않고 화면이 스크롤되지 않아야 한다.
- 시즌1 화면에는 강화석·사냥터가 없고 기록 화면에는 펫 항목이 없어야 한다.
- 다섯 기본 메뉴, 기록 메뉴, 시즌2 사냥터를 직접 이동해 뒤로 가기와 주요 버튼을 확인한다.
- 기준 시안과 시즌2 용검 +16 화면을 같은 크기의 한 이미지에 나란히 놓고 글꼴, 간격, 색,
  이미지, 아이콘과 문구를 비교한다.
- 기기 세이브는 화면 검증 전 백업하고 검증 뒤 원래 값으로 복원한다.
- 전체 단위 테스트, 정적 검사, 디버그·릴리스 조립을 통과해야 한다.
