# 시즌별 대장간 인터페이스 설계

## 목표

- 강화 흐름을 방해하지 않는 한 화면 구성을 유지한다.
- 검 스프라이트와 게임 규칙은 건드리지 않고 화면 표현만 통일한다.
- 시즌1과 시즌2의 기능 차이를 장식이 아니라 실제 해금 상태로 보여 준다.
- 상점, 조합, 보관, 단련, 도감과 기록의 하위 화면까지 같은 디자인 언어를 사용한다.

## 시각 체계

공통 바탕은 검은색에 가까운 남색이며, 얇은 외곽선과 직선형 패널로 정보를 묶는다.
카드가 여러 겹 떠 보이지 않도록 그림자와 큰 둥근 모서리는 사용하지 않는다. 제목, 수치,
보조 설명의 명도를 분리하고 화면의 주요 동작에만 시즌 강조색을 쓴다.

| 구분 | 시즌1 | 시즌2 |
|---|---|---|
| 강조색 | 황동·호박색 | 청록·시안색 |
| 배경 | 따뜻한 대장간 조명 | 차가운 심층 대장간 조명 |
| 재화 | 골드·조각·방지권 | 골드·조각·방지권·강화석 |
| 주요 기능 | 강화와 기본 메뉴 | 강화석, 사냥터와 심층 콘텐츠 추가 |
| 기록 메뉴 | 기본 기록만 노출 | 펫 등 해금된 심층 기록 노출 |

시즌 판정은 현재 장착한 검이 아니라 `Unlocks.deepUnlocked`를 따른다. 한 번 용검을 얻은 뒤에는
다른 검을 들어도 시즌2 표현과 기능이 유지된다.

## 화면 규칙

### 대장간

최고 기록, 재화, 검, 이름과 단계, 계열 효과, 결과 확률, 비용, 소모품, 강화 버튼, 하단 다섯
메뉴 순서를 고정한다. 시즌2에서만 강화석 요구량과 사냥터 진입을 추가한다. 두 시즌 모두
세로 스크롤 없이 조작 요소가 화면 안에 있어야 한다.

### 기본 메뉴

상점·조합·보관·단련·도감은 공통 헤더, 시즌 표식, 재화 표시, 패널과 버튼을 사용한다.
아이콘은 Material 아이콘을 사용하며 이모지나 문자 기호로 대신하지 않는다. 각 화면의 기존
게임 기능과 데이터는 그대로 유지한다.

### 시즌 전용 노출

- 시즌1에는 강화석과 사냥터 진입을 표시하지 않는다.
- 시즌1 기록 메뉴에는 펫처럼 아직 획득할 수 없는 항목을 표시하지 않는다.
- 시즌1 보관함의 빈 상태는 사냥터 이용을 전제로 안내하지 않는다.
- 시즌2에는 실제 해금된 심층 기능만 추가하고 시즌1의 기본 흐름은 그대로 둔다.

## 리소스와 구현

- 계절별 배경은 `drawable-nodpi`에서 원본 비율을 유지해 화면을 채운다.
- `ForgeSeasonTheme`가 시즌별 색 체계를 선택한다.
- `ForgeBackdrop`, `ForgePanel`, `ScreenHeader`, `WalletBar`가 공통 구조를 담당한다.
- 모든 기존 검 이미지는 원본 리소스를 그대로 사용한다.

## 검증 기준

- `SM_A165N` 1080×2340, 450 dpi 실기기에서 확인한다.
- 시즌1과 시즌2 대장간에서 하단 메뉴가 잘리지 않고 화면이 스크롤되지 않아야 한다.
- 다섯 기본 메뉴, 기록 메뉴, 시즌2 사냥터를 직접 이동해 뒤로 가기와 주요 버튼을 확인한다.
- 기준 시안과 실제 화면을 한 이미지에 나란히 두고 글꼴, 간격, 색, 이미지, 문구를 비교한다.
- 전체 단위 테스트, 정적 검사, 디버그·릴리스 조립을 통과해야 한다.
