# v1.3 "살아있는 사냥터" 설계

2026-07-27. 두 번째 실기기 플레이 이후 확장. 목표는 두 가지다 —
**사냥이 매번 다르게 흘러가게** 만들고, **눈에 보이는 모든 것에 그림을 입힌다**.

승인된 방향: A안(사냥 허브) + 회랑은 독립 모드로 크게. 사용자 지시는
"니가 생각한 모든 것들을 전부" — 아래가 그 전부다.

## 배경

v1.2까지의 상태:

- 강화(파괴·방지권·줍기·자동강화) + 사냥 10구역 + 보관함 + 조합 + 재료 강화 + 스타포스
- 검은 픽셀아트 시트(30종 × 낡음 3단계)가 있으나 **몬스터·보스는 색 사각형**이다
- 사냥은 "탭 → 골드"의 반복. 변수가 없어 세 구역쯤 돌면 단조롭다
- 조합 결과는 "더 높은 단계의 같은 검"뿐이라 조합에 꿈이 없다

## 전체 구성 — 일곱 기둥

| # | 기둥 | 한 줄 요약 |
|---|---|---|
| 1 | 아트 전면 개편 | 몬스터 40칸 시트 + 데미지 팝업 + 치명타 + 구역 분위기 |
| 2 | 고유검 10종 | 숨겨진 레시피 조합 → 고유 이름·그림·패시브 |
| 3 | 계열 2종 추가 | 합검·허검. 조합·회랑 전용 획득. 도감 154칸 |
| 4 | 사냥 랜덤 이벤트 8종 | 보물 몬스터·골든타임·미믹·상인·정예·금덩이·유성우·수상한 알 |
| 5 | 펫 10종 | 보스 알 드롭 → 장착 1마리, 자동 타격·보너스. 레벨 1~5 |
| 6 | 일일 퀘스트 | 일 3개 + 주간 1개. 로컬 자정 리셋. 주간 보상은 펫 알 |
| 7 | 무한 회랑 | 독립 로그라이트 모드. 층 + 갈림길 3택 + 사망 페널티 |

전부 기존 사냥·강화 루프에 꽂힌다. 회랑만 별도 화면 체계를 가진다.

## 1. 아트 전면 개편

### 몬스터 스프라이트

- `monster_sheet.png` 한 장 — 잡몹 30종 + 보스 10종 = **40칸**. 검 시트와 같은
  방식: `inScaled=false`, `FilterQuality.None`, 칸 좌표는 코드 상수
- 조달: CC0 픽셀 에셋(Dungeon Crawl Stone Soup 타일셋 등)에서 선별.
  적합한 소스가 없으면 스크립트로 자체 제작(검 시트 때와 같은 접근).
  출처·라이선스는 인앱 라이선스 화면에 기록
- `Zone`의 몬스터마다 시트 칸 번호를 매핑. **테스트로 40칸 전부 매핑 존재·중복 없음을 검증**
- 희귀 몬스터 = **금색 틴트**(ColorFilter). 별도 그림을 만들지 않는다
- 보스 남은 시간 25% 이하 = **붉은 틴트 + 흔들림** — 급해지는 감각

### 타격감 (juice)

지금 사냥이 심심한 첫 번째 이유. 탭의 결과가 몸에 안 남는다.

- **데미지 숫자 팝업** — 탭 지점에서 숫자가 튀어올라 사라진다. 치명타는 크고 노랗게
- **치명타** — 기본 5%, 데미지 1.8배. 판정은 `:core` (`Combat.rollDamage(rng)`),
  펫·고유검이 확률을 올린다
- **처치 연출** — 몬스터가 하얗게 번쩍이며 사라지고 골드 텍스트가 떠오른다
- 몬스터 피격 시 좌우 미세 흔들림

### 구역 분위기

- 구역마다 배경 그라디언트 색 2개 (`Zone`에 상수 추가) — 초원 녹색, 화산 적색, 심연 보라…
- 구역 이름 옆 작은 상징 문자는 유지

## 2. 고유검 — 숨겨진 레시피 10종

조합(Fusion)의 확장이다. 재료 구성이 레시피와 맞으면 일반 결과 대신 고유검이 나온다.

### 규칙

- `Sword`에 `uniqueId: String? = null` 추가. 기본값이라 **옛 세이브 그대로 열린다**
- 레시피 매칭은 `Fusion.resultOf` 앞단 — 맞으면 고유검, 아니면 기존 규칙
- 고유검도 강화·스타포스·판매 전부 가능. 단 **조합 재료로는 못 쓴다**(실수 소멸 방지)
- 일부 레시피는 **보스 재료**를 요구한다. 재료는 새 자원 `essence`(구역 정수)로 통일 —
  보스 처치 시 해당 구역 정수 1개. 인벤토리에 구역별 카운트
- 도감에 고유검 페이지 신설. 미발견은 "???" + 힌트 한 줄 ("성스러운 것 셋이 모이면…")

### 10종 (이름 · 레시피 · 패시브)

| 고유검 | 레시피 | 패시브 |
|---|---|---|
| 삼위일체 | 성검 3자루 (+10 이상) | 보스 데미지 +40% |
| 탐식자 | 마검 2 + 아무 검 2 | 조각 획득 2배 |
| 용왕의 송곳니 | 용검 2자루 (+15 이상) + 용의 둥지 정수 3 | 화상 데미지 3배 |
| 행운아 | 곡도+세검+쌍검+창검 | 검 드롭률 2배 |
| 불사조 | 성검+마검 (+12 이상) + 화산 정수 3 | 파괴 시 1회 부활(-3단계로 생존, 소모됨) |
| 절단자 | 대검+도끼검 (+14 이상) | 치명타 확률 +10%p |
| 폭풍우 | 세검 3 + 설원 정수 2 | 탭 최소 간격 -30% |
| 심연을 삼킨 검 | 마검 3 (+16 이상) + 심연 정수 5 | 몬스터 최대체력 2% 추가 데미지 |
| 개화 | 정령검 + 아무 검 3 | 골드 획득 +50% |
| 시작의 검 | 직검 4자루 | 강화 성공률 +3%p (장착 중) |

수치는 밸런스 시뮬레이션 후 조정될 수 있다. 표가 아니라 코드가 진실.

## 3. 조합·회랑 전용 계열 — 합검·허검

| 계열 | 획득 | 전투 특성 |
|---|---|---|
| 합검(FUSED) | 서로 다른 4계열을 한 번에 조합 | 콤보 +2%/탭, 보스 +25%, 조각 +25% — 두루 좋음 |
| 허검(VOID) | 무한 회랑 10층 최초 클리어 보상 | 한 방 0.5배 + **적 최대체력 1.5% 추가** — 고구역 특화 |

- `WeaponFamily` 14종. 도감 14 × 11 = **154칸**
- 상점에서 살 수 없다. 해금 조건은 도감에 명시
- 스프라이트는 기존 검 시트 규칙(스트라이드 7)이 그대로 덮는다 — 30과 서로소 유지 확인

## 4. 사냥 랜덤 이벤트 8종

잡몹 처치 시 다음 몬스터 등장 롤에서 판정. 기본 확률 8%(희귀 9%와 독립).
이벤트 종류는 가중치 추첨이며 **유성우만 가중치를 극단적으로 낮게**(체감 1% 미만) 둔다.
동시에 두 이벤트는 없다 — 지속형 버프(골든타임) 중에는 새 이벤트 판정을 멈춘다.

| 이벤트 | 내용 | 긴장 |
|---|---|---|
| 보물 몬스터 | 5초 안에 잡으면 골드 10배. 못 잡으면 도망 | 연타 폭발 |
| 골든타임 | 30초간 골드·조각 2배 버프 | 쉬지 않고 돌기 |
| 미믹 | 체력 2배. 잡으면 검 드롭 확정(+1 보정) | 참을까 말까 |
| 떠돌이 상인 | 20초간 배너 — 탭하면 아이템 1개 30% 할인 구매 | 즉석 결정 |
| 분노한 정예 | 체력 3배 · 보상 5배. 도망가지 않는다 | 묵직한 한 판 |
| 금덩이 | 화면에 금덩이가 떨어진다. 3초 안에 탭 = 즉시 골드 | 공짜, 손만 빠르면 |
| 유성우 | 금덩이가 5개 연속으로 떨어진다 (최저 가중치 잭팟) | 잭팟 |
| 수상한 알 | 잡으면 낮은 확률(20%)로 펫 알, 아니면 조각 | 복권 |

- 판정·상태 전이는 전부 `:core` (`HuntEvents`). 화면은 그리기만
- 이벤트 발생 확률은 펫 보너스로 오를 수 있다
- 이벤트마다 등장 효과음 1종 (합성)

## 5. 펫 10종

### 획득·성장

- 보스 처치 시 **5% 알 드롭**(구역 테마 펫). 회랑 25층 · 주간 퀘스트도 알을 준다
- 같은 펫 알 중복 = 레벨업. **레벨 1~5**, 효과가 레벨에 비례
- 장착은 1마리. 보관·교체 자유, 소모·상실 없음

### 10종 (구역 테마 · 효과)

| 펫 | 출신 | 효과 (Lv1 → Lv5) |
|---|---|---|
| 들개 새끼 | 초원 | 자동 타격 DPS 공격력의 10% → 30% |
| 숲 요정 | 숲 | 골드 +6% → +18% |
| 동굴 박쥐 | 동굴 | 이벤트 확률 +1%p → +3%p |
| 광산 두더지 | 폐광 | 조각 +8% → +24% |
| 늪 개구리 | 늪지 | 검 드롭률 +20% → +60% (곱연산) |
| 불도롱뇽 | 화산 | 치명타 +2%p → +6%p |
| 눈여우 | 설원 | 보스 제한시간 +1초 → +3초 |
| 새끼용 | 용의 둥지 | 자동 타격 + 화상 부여 |
| 그림자 고양이 | 심연 | 희귀 몬스터 확률 +2%p → +6%p |
| 회랑의 정령 | 무한 회랑 | 회랑 보상 +10% → +30% |

- 펫 도감 페이지 신설(미획득 실루엣). 스프라이트는 몬스터 시트에 10칸 추가 (총 50칸)
- 효과 계산은 `:core` `Pets` — 전부 순수 함수, 테스트로 상한 검증

## 6. 일일 퀘스트

- **일일 3개 + 주간 1개.** 로컬 날짜 기준 자정(주간은 월요일) 리셋. 서버 없음
- 풀에서 무작위 추첨: 잡몹 N · 보스 N · 강화 N회 · 강화 성공 N회 · 조합 N회 ·
  별 강화 N회 · 이벤트 N회 조우 · 회랑 N층
- **아직 해금 안 된 컨텐츠의 퀘스트는 풀에서 뺀다** — 회랑 미해금이면 회랑 퀘스트가
  나오지 않는다. 못 깨는 퀘스트를 받으면 하루를 버리는 기분이 든다
- 진행도는 기존 통계 카운터의 **스냅샷 차분**으로 계산 — 배정 시점 값을 저장해 두고
  현재 값과의 차이를 진행도로 쓴다. 카운터 재활용이라 구현이 싸다
- 보상: 일일 = 골드·조각·아이템 / 주간 = **펫 알 1개(무작위)**
- UI: 강화 화면 상단에 미수령 보상 배지, 퀘스트 화면은 기록 메뉴와 강화 화면 양쪽에서 진입

## 7. 무한 회랑 — 독립 로그라이트 모드

### 입장과 해금

- 강화 화면의 "회랑" 버튼. 해금: **화산 보스 처치** (중반부터 열려야 컨텐츠로 산다)
- 장착한 검·펫을 들고 들어간다. 검은 회랑에서 절대 부서지지 않는다

### 런 구조

```
1층: 웨이브(잡몹 5마리, 제한 25초) → 갈림길 3택 → 2층 → … 5층: 회랑 보스 → …
```

- **웨이브**: 제한시간 내 전부 처치. 실패 = 런 종료
- **갈림길 3택** (매 층 사이, 무작위 제시):
  - **축복** — 런 한정 버프 (공격력 +20% · 시간 +3초 · 골드 +50% · 치명타 +5%p … 중 1)
  - **보물** — 즉시 골드/조각. 위험 없음
  - **저주받은 방** — 다음 웨이브 체력 2배, 보상 4배
- **5층마다 회랑 보스**, 처치 시 **체크포인트** — 그때까지 보상 전액 확정
- 런 종료(시간초과): 체크포인트 이후 보상은 **70%만** 들고 나간다
- 층 스케일: `체력 = 기준 × 1.35^층`. 상한 없음 — 최고 기록이 목표

### 보상·메타

- 골드·조각 (층 비례), **회랑 정수**(고유검 재료로도 쓰임)
- 10층 최초 클리어: **허검 해금** / 25층: 펫 알(회랑의 정령) / 최고 층 기록·업적·칭호
- 런 한정 버프는 나가면 사라진다. 영구 성장은 기록·해금뿐 — 파워는 본편에서 온다

### 구현

- `GauntletEngine` 순수 Kotlin — 층 생성·판정·보상 계산 전부. 가상 시간 테스트
- `GauntletScreen` — 사냥 화면 부품(몬스터 스프라이트·데미지 팝업) 재사용

## 8. 사운드 추가

합성 사운드 8종 추가: 이벤트 등장 · 보물 몬스터 도망 · 금덩이 획득 · 고유검 탄생 팡파르 ·
펫 알 획득 · 펫 레벨업 · 회랑 갈림길 선택 · 회랑 체크포인트. 기존 13종과 같은 방식(파일 없음).

## 9. 저장·호환·구조

- 새 필드 전부 기본값: `uniqueId`, `essences`, `pets`, `equippedPet`, `quests`,
  `gauntletBest`, 이벤트 상태(저장 안 함 — 휘발). **옛 세이브 무손실**
- 도메인은 전부 `:core`: `HuntEvents` `UniqueSwords` `Pets` `DailyQuests` `GauntletEngine`

- 밸런스 시뮬레이션 확장: 이벤트·펫 수입을 넣고 골드 인플레가 목표 범위인지 재검증
