# v2.3 — 조합 개편과 긴 시즌1

날짜: 2026-08-02
상태: 승인됨 (구현 완료)

## 목표

시즌1(용검 이전)을 **최대한 길게**. 강화가 주 컨텐츠라는 축은 그대로 두고,
+20 이 "한 번 넘는 벽"에서 "여섯 번 밟는 경유지"가 되도록 조합을 다시 짠다.

## 결정 사항

### 1. 시작 상태
- 새 게임 = **직검 +0 한 자루 + 1,000골드** (`SaveStore.newGame`).
- 처음부터 상점에서 검을 사는 흐름을 없앤다. 초기화도 같은 상태로 돌아온다.

### 2. 행운부적 = 하락 없음만
- 부적은 실패 시 **하락만** 막는다. 파괴 판정은 언제나 돈다.
- 파괴에서 살리는 것은 방지권의 몫 — 부적이 파괴까지 막으면 방지권이 죽은 물건이 된다.
- **화면의 파괴 확률도 부적을 켠 채 그대로 보여야 한다** (`ForgeOdds`).
  부적을 켜면 파괴 0%로 표시하던 옛 계산은 지금 규칙에서는 거짓말이다.
- 불사조의 "파괴 시 부활" 패시브 삭제 → **사냥 골드 +25%** 로 교체.

### 3. 파괴 확률 인하 (1~20) — 두 차례
- 13~15: 0.40 → 0.25 → **0.125**, 16~18: 0.60 → 0.40 → **0.20**, 19~20: 0.80 → 0.55 → **0.275**.
- 시즌1이 길어진 것은 조합이 맡는다 — 파괴까지 잦으면 길이가 아니라 고문이 된다.
  계열 넷을 전부 +20까지 올려야 하는 지금, 파괴 한 번은 한 계열을 통째로 되돌린다.
- +21 위는 1.00 그대로 (전설검은 파괴 대신 +21 복귀).

### 4. 고유검 강화 불가
- 고유검은 벼려진 그대로다 — 강화대에 오르지 않는다 (`ForgeEngine.canRoll`).
- 시작의 검: "장착 중 +3%p" → **소유만으로 +3%p** (`UniqueSwords.originOwned`),
  재료 하한 직검 +10 둘 (320골드에 영구 보너스는 너무 쌌다).

### 5. 계열 조합 = +20 의식 (명칭은 「조합소/조합」 유지)
- 새 도메인 `Refinery`: **직검+20 + 곡도+20 = 마검+1**, **대검+20 + 세검+20 = 성검+1**.
- 마검+20 + 성검+20 = 용검+21 은 기존 `LegendForge` 그대로.
- 아무 단계나 섞어 평균 내던 일반 조합(`FusionTable`) 삭제.
  `Fusion` 은 고유검 레시피 전용으로 남는다.
- 결과는 보관함으로 들어간다. 손을 비울 필요 없다.
- 세검 해금: "조합 1회" → **아무 검 +15 달성** (일반 조합이 사라져 못 쓰게 됐다).

### 6. +10 위 판매가 인하 — 세 밴드
- `Economy.sellPrice`: +10 까지 **1.80**(파산 나선 방지 구간, 손대지 않는다) /
  +11~14 **1.50** / +15~20 **1.20** / +21 위 1.35.
- +15: 298,246 → **238,596**, +20: 1,400만 → 226만 → **593,704**.
- +15~20 의 증가율은 **비용 증가율(1.45)보다 낮다.** 의도한 것이다 —
  이 구간은 돈을 버는 구간이 아니라 조합 재료(+20)를 만드는 구간이고,
  벌이는 +14 아래의 회전이 맡는다. 그래서 한계 증가율 불변식은 +14 까지만 건다.

## 밸런스 (시뮬레이터, 맨손 NORMAL 2,000회)
- 평균 최고 단계 15.9 (구간 15~18), 상한 도달률 0.17% (구간 0.05%~5%), **파산율 0%**.
- 한 세션으로 +20 에 닿기는 어렵되 **막다른 길은 아니다** — 파산율 0%가 그 증거다.
- 실플레이는 스킬·도감·고유검 보너스가 영구히 쌓여 회차마다 빨라지고,
  세션도 한 번으로 끝나지 않는다.

## 실기기 피드백 2차 — 사냥터·고유검·소모품

### 7. 사냥터를 용검 기준으로 재편성
- 사냥은 용검(+21) 뒤에야 열리는데 구역 사다리는 권장 0~38 이었다.
  **앞의 열 구역이 전부 새 용검보다 약했다** — 들어가자마자 걸어 다니는 곳이었다.
- 24개 구역 전부 권장 단계 **+15** (초원 15, 끝의 문 53).
- 체력은 화력 곡선에 맞춰 ×1.5^15, 골드는 강화 비용 곡선에 맞춰 ×1.45^15.
  체력과 골드를 같은 배수로 올리면 "한 바퀴 = 강화 N번치" 가 어긋난다
  (`HuntIncomeTest` 가 잡았다 — 초원 한 바퀴가 25번치에서 41번치로 튀었다).
- `Essences.weightOf` 는 이제 **가장 얕은 구역으로부터의 거리**다. 권장 단계를
  그대로 쓰면 사다리를 올릴 때마다 정수 무게가 통째로 뛰어 수호 각인이 헐값이 된다.

### 8. 고유검에 닿는 길 복원
- v2.3에서 마검·성검이 「+20 두 자루의 의식」이 되면서, 그 둘을 요구하던 레시피 넷이
  사실상 도달 불가가 됐다(마검 둘 = 기본 검 +20 **네 자루**).
- 정수 없는 레시피 넷을 **기본 4계열 하나씩**으로 옮겼다:
  직검+10 둘 → 시작의 검 / 곡도+12 둘 → 탐식자 / 세검+12 둘 → 폭풍우 /
  대검+14 둘 → 삼위일체. 마검·성검을 쓰는 둘(심연·불사조)은 정수까지 필요한 시즌2 몫.
- `UniqueSwordsTest` 에 「기본 4계열마다 정수 없는 레시피가 하나씩 있다」를 추가해
  같은 일이 다시 일어나지 않게 막는다.

### 9. 소모품 값 10배
- 800/1,200/2,000 → **8,000/12,000/20,000**.
- 예전 값은 +5 검 한 자루 값이라 고민거리가 아니었다. 시뮬레이터가 방지권을
  **다섯 장까지 상시 비축**하며 파괴마다 되살렸다 — 파괴 구간이 벽이 아니었던 진짜 이유다.
- 얼마나 올릴지는 시뮬레이션이 정했다. 100,000/160,000/250,000 으로는 20,000판 중
  +20 도달이 0명이 되고 최고 단계가 17에서 멈췄다 — 어려워진 게 아니라 길이 막힌 것이다.
  10배가 천장(+20)이 남아 있는 가장 비싼 값이었다.
- `BalanceSimulationTest` 의 「길이 있다」 판정을 도달률에서 **최고 단계 == 20** 으로 바꿨다.
  도달률은 값 하나에 0.17% ↔ 0.01% 로 흔들리는 꼬리 통계라 회귀를 알려 주지 못한다.

## 실기기 피드백 3차 — 화면 언어 정리

### 10. 「둘 중 하나만 걸 수 있다」 삭제
- v2.1에서 축복서+부적 배타를 풀었는데 안내문만 남아 거짓말을 하고 있었다.
- "둘 다 함께 켤 수 있다 · 켠 것은 이번 강화에 쓰인다"로 교체.

### 11. 벼리다/벼리기 전면 퇴출
- 화면에 보이는 모든 한국어에서 조합/강화로 통일 (사용자: "헤깔려").
- 용검 조합 — 전설 / 재료로 조합 / 다시 조합 / 고유검 힌트 "+N까지 강화해…" /
  막힘 사유 "고유검은 완성된 검이다 — 강화할 수 없다".
- 도메인 이름(LegendForge 등)과 코드 주석은 그대로 — 화면 언어만의 규칙이다.

### 12. 확률 소수점 2자리
- `OddsPercent` 를 정수%에서 **만분율 반올림 Double**로. 넷의 합은 정확히 100.00.
- 정수%는 도감 한 장(+0.1%p 수준)의 변화를 통째로 삼켰다 — 쌓는 재미는
  숫자가 움직이는 게 보여야 생긴다.
- 강화 화면 성공/유지/하락/파괴, 보너스 내역 %p, 통계 비교표까지 전부 2자리.

### 13. 통계 화면 시즌 분리
- 시즌1에서는 "모은 조각" 행과 "사냥과 수집" 카드를 숨긴다.
- 자리에 "용검을 조합하면 사냥과 수집 통계가 열린다" 한 줄.

## 실기기 피드백 4차 — 워프 경제 (죽음도 밑천)

### 14. 워프권 — 조각으로 사는 「그 단계에서 시작하는 검」
- 조각 교환 3종: **+5(120) / +10(400) / +15(850, 신설)**. 시즌1부터, 빈손일 때.
- 파괴 → 줍기가 **시즌1에서도 조각**을 준다(골드 대체 폐지). 회수 배수 2→3 (단계×3×0.7~1.3).
- **파괴는 +10부터** (10~12: 10% / 13~15: 12.5% / 16~18: 20% / 19~20: 27.5%).
  파괴가 잃는 것이 아니라 다른 화폐로 바뀌는 것이 됐으므로 더 일찍 시작해도 된다.
- 조각은 지갑·통계에 시즌1부터 표시. 단 **시즌1 조각의 쓸 곳은 워프권뿐** —
  방지권(10조각)·강화석 교환을 열어 두면 파괴 한 번이 방지권 서너 장이 되어
  소모품 골드값 10배가 조각 뒷문으로 무너진다. 게이트는 `Recipes.canCraft`(도메인)에 있다.
- 어떤 워프권도 그 단계 파괴 한 번의 조각보다 싸면 안 된다 — 순환 이득 방지.

### 15. 보너스는 하락방지로
- 도감·스킬·고유검·계열의 guard 축을 **파괴방지 → 하락방지**로 (`dropGuard` 개명).
  막히면 유지. **파괴를 막는 것은 방지권뿐**(전설은 수호 각인).
- 시뮬레이터: 워프권을 검 확보에 사용(+15부터 시도), 자금 판매 단계 10→9
  (+10부터 파괴라 10을 노리면 자금 판의 10%가 부서진다).
- 시뮬 결과(맨손 NORMAL): 평균 15.0, 최고 20 유지, 파산 0%.

## 지키는 불변식 (테스트)
- 기본 4계열 +0 판매가 < 구매가 160 (사서 되팔기 손해).
- 조합해 팔기 < 재료 판매 (조합은 가격표가 아니라 계보).
- 전설 재료(마검·성검)는 전부 `Refinery.RECIPES` 로 만들 수 있고,
  그 재료는 전부 기본 4계열이다 (`FamilyUnlockReachTest` — 시즌1 데드락 방지).
