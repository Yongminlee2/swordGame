# v2.3 — 조합 개편과 긴 시즌1

날짜: 2026-08-02
상태: 승인됨 (구현 완료)

## 목표

시즌1(용검 이전)을 **최대한 길게**. 강화가 주 컨텐츠라는 축은 그대로 두고,
+20 이 "한 번 넘는 벽"에서 "여섯 번 밟는 경유지"가 되도록 조합을 다시 짠다.

## 결정 사항

### 1. 시작 상태
- 새 게임 = **직검 +0 한 자루 + 1,000골드** (`SaveStore.newGame`).
- 처음부터 상점에서 검을 사는 흐름을 없앤다. 초기화도 같은 상태로 돌아온다.

### 2. 행운부적 = 하락 없음만
- 부적은 실패 시 **하락만** 막는다. 파괴 판정은 언제나 돈다.
- 파괴에서 살리는 것은 방지권의 몫 — 부적이 파괴까지 막으면 방지권이 죽은 물건이 된다.
- 불사조의 "파괴 시 부활" 패시브 삭제 → **사냥 골드 +25%** 로 교체.

### 3. 파괴 확률 인하 (1~20)
- 13~15: 0.40 → **0.25**, 16~18: 0.60 → **0.40**, 19~20: 0.80 → **0.55**.
- 시즌1이 길어진 것은 조합이 맡는다 — 파괴까지 잦으면 길이가 아니라 고문이 된다.
- +21 위는 1.00 그대로 (전설검은 파괴 대신 +21 복귀).

### 4. 고유검 강화 불가
- 고유검은 벼려진 그대로다 — 강화대에 오르지 않는다 (`ForgeEngine.canRoll`).
- 시작의 검: "장착 중 +3%p" → **소유만으로 +3%p** (`UniqueSwords.originOwned`),
  재료 하한 직검 +10 둘 (320골드에 영구 보너스는 너무 쌌다).

### 5. 계열 조합 = +20 의식 (명칭은 「조합소/조합」 유지)
- 새 도메인 `Refinery`: **직검+20 + 곡도+20 = 마검+1**, **대검+20 + 세검+20 = 성검+1**.
- 마검+20 + 성검+20 = 용검+21 은 기존 `LegendForge` 그대로.
- 아무 단계나 섞어 평균 내던 일반 조합(`FusionTable`) 삭제.
  `Fusion` 은 고유검 레시피 전용으로 남는다.
- 결과는 보관함으로 들어간다. 손을 비울 필요 없다.
- 세검 해금: "조합 1회" → **아무 검 +15 달성** (일반 조합이 사라져 못 쓰게 됐다).

### 6. +10 위 판매가 인하
- `Economy.sellPrice`: +10 까지 1.80 그대로(파산 나선 방지 구간), **+11~20 은 1.50**,
  +21 위 1.35 그대로.
- +20 판매가 1,400만 → 226만. 골드가 뜻을 잃지 않는다.

## 밸런스 (시뮬레이터, 맨손 NORMAL 2,000회)
- 평균 최고 단계 16.6 (구간 15~18), 상한 도달률 2.2% (구간 0.5%~15%), 파산율 0%.
- 실플레이는 스킬·도감·고유검 보너스가 영구히 쌓여 회차마다 빨라진다.

## 지키는 불변식 (테스트)
- 기본 4계열 +0 판매가 < 구매가 160 (사서 되팔기 손해).
- 조합해 팔기 < 재료 판매 (조합은 가격표가 아니라 계보).
- 전설 재료(마검·성검)는 전부 `Refinery.RECIPES` 로 만들 수 있고,
  그 재료는 전부 기본 4계열이다 (`FamilyUnlockReachTest` — 시즌1 데드락 방지).
