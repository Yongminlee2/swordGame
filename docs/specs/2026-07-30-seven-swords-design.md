# v2.1 「일곱 자루」 — 노출 축소와 조합 단순화

날짜: 2026-07-30. 실기기 첫 플레이 피드백에서 나온 대개편이다.

## 왜

계열 14종·조합 2~4자루·고유검 10종·퀘스트·회랑이 전부 첫 화면 언저리에 있었다.
처음 하는 사람이 읽어야 할 것이 너무 많았고, 정작 핵심(강화 한 번의 긴장)이 묻혔다.
**지금은 일곱 자루만 보여 준다. 나머지는 지우지 않고 숨긴다** — 출시 뒤 콘텐츠로 되살린다.

## 1. 노출 계열 7종

직검 · 곡도 · 대검 · 세검 · 마검 · 성검 · 용검. 단일 출처는 `WeaponFamily.VISIBLE`.
도감·조합·상점·고유검·도움말·통계·업적·계열 특성 표가 전부 이것만 본다.

- 숨김이지 삭제가 아니다. enum·저장 필드·계열 특성 코드는 그대로 둔다.
- 옛 세이브에 숨긴 계열 검이 있으면 그대로 보이고 장착·판매·분해도 된다.
  **새로 얻을 길만 없다.** 몰수하면 세이브가 깨진 것처럼 보인다.

## 2. 전설 = 용검

- 용검은 +21에서 시작한다. 20강 이하 용검은 숨긴다 (도감 용검 계열 구획 없음).
- 획득: 조합소 전설 칸에서 **마검+20 + 성검+20 → 용검+21**. 재벼림(조각 500) 유지.
- 파괴 시 +21 복귀, 전설 특성(+3%p/+3%p/담금질 상한 +20%p) 유지. 이름만 용검이다.

## 3. 조합 = 정확히 2자루

- 결과 단계 = **(a+b)÷2 내림**. 조합은 단계가 아니라 **계열을 만드는 장치**다.
- 조합표는 둘: `직검+곡도=마검`, `대검+세검=성검`. 표에 없는 조합은 불가.
  같은 계열 보너스·일반 규칙(다수결) 삭제.
- 용검은 표에 없다 — 전설 칸 전용이다. 그래서 불사조(마검+성검 고유검)와 충돌하지 않는다.
- **조합법을 조합소 화면에 항상 표기한다.** 고유검 레시피(정수 요구 포함)도 함께.

## 4. 고유검 6종 + 정수의 용도

남는 것: 시작의 검(직검2) · 탐식자(마검2) · 심연을 삼킨 검(마검+16 2) ·
삼위일체(성검+10 2) · 폭풍우(세검2) · 불사조(성검+마검 +12).
숨는 것: 용왕의 송곳니 · 절단자 · 행운아 · 개화.

- 레시피는 전부 **재료 2자루**로 재정의 (조합이 2자루라서).
- **정수 = 고유검 촉매.** 조합소 레시피 목록에 "OO 정수 N개"를 명시한다.
- 보유 보너스 `PER_UNIQUE` 0.003 → 0.005 (6종 만점 = +3.0%p 유지).

## 5. 도감 156칸

노출 6계열(용검 제외)×21 + 용검(전설) 30 = 156. `SLOT_STEP=10`, `STEP_BONUS` 0.001→**0.002**
(만점 ≈ +3.0%p 유지). 옛 세이브의 숨긴 칸은 세지 않되 지우지도 않는다.

## 6. 판정 변경

- **축복서+행운부적 동시 사용 허용.** 배타 제거. 동시에 켜면 성공률↑ + 실패해도 유지.
- **1~20강 확률 상향.** 구간 낙폭을 완만하게. 수치는 시뮬레이터로 확정한다 —
  목표는 +13~+20 구간이 지금보다 확실히 덜 극악할 것. 시뮬레이터 단언 구간도 함께 재조정.
- 세검 해금: 조합 3회 → **조합 1회**. 사다리가 곡도(+10)→대검(구역 3곳)→세검(조합 1회)
  →성검→용검으로 한 방향으로 흐른다.

## 7. 화면 정리

- 퀘스트 숨김 (버튼·화면·배지. 도메인은 잔류).
- 아이콘 **한 줄 5개**: 상점 · 조합소 · 가방 · 단련 · 도감.
- 무한 회랑 버튼 → 사냥 화면 안으로.
- 최근 자취(●·▽✕) 표시·기록 전부 삭제.

## 지켜야 할 선

- `BalanceSimulation` 은 여전히 맨손 신규 플레이어만 잰다. 보너스 유입 금지.
- 전설검을 잃는 자리 금지(`Fusion.meltable`·`Storage.canScrap` 통과 필수).
- 새 저장 필드는 전부 기본값. 옛 세이브는 손실 없이 열린다.
