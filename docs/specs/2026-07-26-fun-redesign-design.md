# 재미 재설계 — 설계 문서

작성일: 2026-07-26
대상: SwordForge v1.0.0 이후 (M8~)

---

## 1. 문제 진단

v1.0.0을 실기기에서 플레이한 결과 나온 문제다.

| 문제 | 원인 |
|---|---|
| **검이 안 이쁘다** | 코드로 그린 도형이고, 계열 8 × **티어 11**이라 `+9`·`+10`·`+11`이 같은 그림이다 |
| **싱겁다** | 소리가 하나도 없다. 강화 게임 손맛의 절반이 "띵"과 "쨍그랑"인데 무음이다 |
| **강화할 이유가 없다** | 강화한 검을 **팔아야** 돈이 된다. 애써 올린 것을 버리는 구조라 목표가 숫자뿐이다 |

세 번째가 구조적 결함이다. "잘 만든 게임"의 문법(경제·수집·통계)을 넣느라
원작의 즉각성과 목적성을 죽였다.

**중심은 강화다.** 전투는 강화의 돈줄로 붙는 보조 시스템이며, 강화 화면이 계속 홈이다.

## 2. 범위와 순서

| 마일스톤 | 내용 | 근거 |
|---|---|---|
| **M8** | 검 아트 전면 교체 | 가장 급한 문제. 이것만으로 체감이 크게 달라진다 |
| **M9** | 사운드 | 작업량이 작고 "싱거움"이 바로 해결된다 |
| **M10** | 사냥 + 보스 | 강화할 이유를 만든다. 경제의 중심축을 옮긴다 |

각 마일스톤 완료 시 APK를 전달해 확인받는다.

## 3. M8 — 검 아트 전면 교체

### 조달

**game-icons.net**, CC BY 3.0. 검·칼 126개, 무기 174개. SVG가 512×512 뷰박스의
단일 `path`라 안드로이드 `VectorDrawable`로 그대로 옮겨진다. 실측 확인했다.

- 이미지 파일(PNG 등)을 넣지 않는다. `path` 데이터만 벡터 XML로 만든다
- 벡터 XML 160개면 수백 KB. 릴리스 APK는 1MB대를 유지한다
- **CC BY 3.0은 표기가 의무다.** M6에서 만든 설정 → 라이선스 화면에 출처
  (game-icons.net, 아이콘 제작자명, CC BY 3.0, 원본 링크)를 넣는다

타사 상용 게임의 리소스는 여전히 쓰지 않는다.

### 구조 변경 — 단계마다 다른 실루엣

지금은 계열 8 × 티어 11이라 한 티어가 2~3단계를 덮는다. 이것을 **단계별 실루엣**으로 바꾼다.

```
계열 8종 × 강화 단계 0~20 = 168 슬롯
→ 계열마다 별도 실루엣 세트를 배정
→ 단계가 오르면 실루엣이 바뀐다 (+9, +10, +11 이 전부 다른 검)
→ 티어별 색·오라·파티클을 얹어 등급감을 준다
```

아이콘 수가 슬롯보다 적으므로 일부 구간은 실루엣을 공유하고 색·장식으로 구분한다.
**다만 3단계가 통째로 같은 그림인 상황은 없앤다.**

무한 모드(+21 이상)는 최상위 실루엣을 유지하고 색과 오라만 강해진다.

### 코드 경계

`ui/SwordArt.kt` 를 "파라미터 조립"에서 "아이콘 조회 + 색 입히기"로 바꾼다.
M5에서 검 그리는 지식을 이 파일 하나에 가둬 둔 덕분에 다른 코드는 손대지 않는다.

`WeaponTier` 는 이름 표시와 도감 구성에 계속 쓰이므로 남긴다. 그림만 단계 기준으로 바뀐다.

### 검증

- 단계 0~20 × 계열 8종 전부 대응 실루엣이 있는지 테스트로 확인
- 인접한 단계가 같은 (실루엣, 색) 쌍을 갖지 않는지 확인
- 라이선스 화면에 사용한 아이콘의 출처가 빠짐없이 들어갔는지 확인

## 4. M9 — 사운드

CC0 사운드 팩(Kenney 오디오 팩 등)에서 조달한다. CC0는 표기 의무가 없다.

| 상황 | 소리 |
|---|---|
| 강화 성공 | 맑은 금속 타격음. 단계가 높을수록 음이 높아진다 |
| 실패 (유지) | 둔탁한 타격음 |
| 하락 | 금속이 긁히는 소리 |
| **파괴** | 유리·금속이 깨지는 소리. 가장 크고 길게 |
| 방지권 발동 | 짧은 상승음 |
| 줍기 | 조각 주워지는 소리 |
| 몬스터 타격 (M10) | 짧은 baek 타격음 |

설정에 **효과음 켜기/끄기**를 추가한다. M6에서 "없는 기능의 스위치를 두지 않는다"며
빼 두었던 항목이다. 이제 소리가 생기므로 넣는다.

## 5. M10 — 사냥과 보스

### 경제를 뒤집는다

```
[전]  강화한 검 → 팔아야 골드 → 다시 강화        (올린 걸 버려야 함)
[후]  검을 들고 사냥 → 골드·조각 → 강화 → 더 센 검 → 더 깊은 구역
```

골드의 출처가 검 판매에서 사냥으로 옮겨간다. 강화한 검을 버릴 이유가 없어지고,
강화할 이유는 "다음 구역을 뚫으려고"가 된다.

딸려오는 변화:

- **파산 구제를 없앤다.** 사냥이 그 문제를 근본에서 지운다. 대신 검이 없으면
  **기본 검을 무료 지급**한다. 검만 있으면 1구역에서 바로 벌 수 있어 막히지 않는다.
  켜자마자 검을 들고 시작하므로 "시작까지 길다"도 같이 해결된다
- **검 판매는 남기되 상점 구석으로 밀어낸다.** 이제 파는 것은 손해이며,
  계열을 바꾸고 싶을 때만 쓰는 기능이다
- **파괴가 훨씬 무거워진다.** 검이 부서지면 강화만 막히는 게 아니라 사냥도 못 한다.
  돈줄이 끊긴다. 방지권의 실질 가치가 오르고 파괴 순간의 2.5초가 진짜로 무거워진다
- 조합소는 그대로. 조각은 사냥 드롭과 줍기 양쪽에서 나온다

### 전투 — 탭 액션

몬스터를 직접 탭해서 때린다. 한 번 탭 = 검 공격력만큼 피해.
HP가 0이 되면 처치하고 골드·조각을 떨어뜨린다.

**더 센 검 = 탭 한 번에 더 크게 깎임**이 손끝으로 느껴진다. 강화할 이유가 체감된다.

전투에서는 검이 부서지지 않는다. 파괴는 강화에서만 일어나야 긴장이 한 곳에 모인다.

### 구역 진행

초원 → 동굴 → 화산 → 용의 둥지 순으로 나아간다.
각 구역 끝에 보스가 있고, 보스를 잡아야 다음 구역이 열린다.
보스는 HP가 크고 제한 시간이 있어 **공격력이 부족하면 시간 안에 못 죽인다.**

이것이 "이 보스 잡으려면 +12는 돼야 한다"는 구체적 목표를 만든다.
클리어한 구역은 다시 가서 사냥할 수 있다.

### 계열별 전투 특성

계열이 외형만 다르던 것을 **싸우는 방식이 다르게** 바꾼다. 수집 이유가 생긴다.

| 계열 | 특성 |
|---|---|
| 직검 | 기준. 특별한 것이 없는 대신 약점도 없다 |
| 곡도 | 연속으로 탭할수록 피해가 조금씩 누적된다 |
| 대검 | 탭 간격이 느리지만 한 방이 세다 |
| 세검 | 빠르게 여러 번 탭할 수 있고 한 방은 약하다 |
| 쌍검 | 한 번 탭에 2연타가 들어간다 |
| 마검 | 피해를 준 만큼 조각을 조금 더 얻는다 |
| 성검 | 보스에게 주는 피해가 크다 |
| 용검 | 화상을 입혀 탭하지 않는 동안에도 피해가 들어간다 |

공격력은 강화 단계에서 나오고, 계열은 그 공격력을 **어떻게 쓰는지**를 정한다.

### 검증

- 계열 8종의 특성이 실제로 서로 다른 결과를 내는지 테스트
- 구역별 보스가 특정 공격력 미만에서는 제한 시간 안에 죽지 않는지 테스트
- 사냥 수입이 강화 비용 곡선을 따라가는지 시뮬레이션으로 확인
  (M1의 `BalanceSimulation`에 사냥 수입을 넣어 재측정)

## 6. 비범위

- 온라인·랭킹·계정
- 광고·인앱결제

## 7. 확정되지 않은 항목

- 사용할 아이콘의 구체적 목록 — M8 구현 중 카테고리를 훑어 고른다
- 구역 수와 몬스터 종류 — M10 설계 시 확정
- 사냥 수입 수치 — M10에서 시뮬레이션으로 잡는다
