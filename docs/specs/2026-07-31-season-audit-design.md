# 시즌 경계 감사 + 계열별 판매가

날짜: 2026-07-31. 시즌1 = +20 이하(사냥 없음, 골드 하나), 시즌2 = 용검(+21)부터.

## 1. 데드락 — 대검 해금이 시즌2에 묶여 있었다

대검 해금 = 구역 3곳 클리어. 그런데 사냥터는 용검 뒤에 열린다.
대검 → 성검 → 용검 사슬이라 **시즌1에서 용검에 영영 닿을 수 없었다.**

고침: **대검 = 파괴 3회.** 해금 사다리가 전부 시즌1 활동이 된다 —
곡도(+10 달성) · 대검(파괴 3회) · 세검(조합 1회). 활동이 서로 다르다는
원래 의도도 유지된다. 파괴는 +13부터 자연히 겪는다.

## 2. 계열별 판매가

같은 단계면 계열 무관 같은 값이었다. 조합검(마검·성검)을 만들어도 판매가가
그대로라 조합의 값어치가 가격에 없었다.

**`Economy.sellPrice(sword)` = 기준 곡선 × 계열 배수.** 단일 출처는 `familyMult`.

| 계열 | 배수 | 근거 |
|---|---|---|
| 직검 | 1.00 | 기준. 시뮬레이터가 도는 계열 |
| 곡도 | 1.05 | 해금 조건 순 |
| 대검 | 1.10 | |
| 세검 | 1.15 | |
| 마검 | 1.50 | 조합 1단 — 재료 둘 + 조합비의 값 |
| 성검 | 1.65 | 재료(대검·세검)가 더 늦게 열린다 |
| 용검 | 2.00 | 전설 |

숨긴 계열도 1.2~1.8 사이 값을 갖는다(옛 세이브 보유분).

**불변식 둘:**
- 기본 4계열 +0 판매가 < 구매가 160 (최대 1.15×110=127). 사서 되파는 순환 차단 유지.
- 조합해 팔기 < 재료 둘을 그냥 팔기 (1.8 곡선의 볼록성 + 평균 단계). 조합은
  가격표가 아니라 계보를 위한 것 — 프리미엄은 손해를 덜어 줄 뿐이다.

기준 곡선(`sellPrice(level)`)은 그대로다 — 시뮬레이터·사냥수입 테스트가 보는 값이다.

## 3. 시즌1 노출 정리

- 상점 **강화석 구매 칸**: 시즌2부터. 시즌1은 강화석을 아예 안 먹는다.
- 보관함 **분해(🔨) 버튼**: 시즌2부터. 조각·강화석을 주는데 시즌1엔 쓸 데가 없다.
- 보관함 머리의 「골드·조각」 줄: 시즌1에는 골드만.
- 조합소 고유검 레시피: **정수를 요구하는 것(심연·불사조·폭풍우)은 시즌2부터** 보인다.
  시즌1은 정수를 얻을 길이 없어 만들 수 없는 목록만 늘어놓게 된다.
  정수 안내문("보스가 준다")도 시즌2부터.
