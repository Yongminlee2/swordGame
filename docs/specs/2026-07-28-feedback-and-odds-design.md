# v1.9 「보이게 만든다」 — 설계

2026-07-28

## 문제

게임이 플레이어에게 말을 안 한다.

- 강화 화면에 **성공률만** 있다. 떨어질 확률과 부서질 확률은 `RateTable` 에 있는데 화면에 없다.
  무한 구간(+21~)은 실패가 곧 파괴인데 그걸 모르고 누른다.
- 보스를 놓치면 알림 한 줄만 뜨고 **잡몹 진행이 조용히 지워진다**(`killsInZone = 0`).
  12마리를 다시 모아야 한다는 사실이 화면 어디에도 없다.
- 보스를 잡으면 골드·조각·강화석·펫 알이 들어오는데 **전부 조용히** 들어간다.
  승리감의 대부분이 여기서 사라진다.
- 특수강화가 강화 화면 한가운데 있어 메인이 길다.

## 설계

### 1. 확률 세 가지

```
🎯 성공  62%      ↓ 하락  30%      💥 파괴  8%
```

| 목표 단계 | 하락 | 파괴 |
|---|---|---|
| ~+5 | 0 | 0 |
| +6~+12 | 실패분 전부 | 0 |
| +13~+20 | 실패분 × (1 − 파괴확률) | 실패분 × 파괴확률 |
| +21~ | 0 | 실패분 전부 |

**켜 둔 아이템이 반영된다.** 축복서는 성공률을 올리고, 행운부적은 하락·파괴를 0으로 만든다.
토글이 무엇을 사는 건지 눈으로 보여야 누를 이유가 생긴다.

새 파일 `core/ForgeOdds.kt` 가 세 값을 계산한다. 화면이 확률을 다시 계산하면 규칙이
두 군데가 되고 반드시 어긋난다. **세 값의 합이 항상 1**임을 테스트가 못 박는다 —
구간 경계에서 새는 확률이 있으면 거기서 잡힌다.

### 2. 사냥 결과 팝업

**패배**

```
     보스를 놓쳤다
  회랑 끝의 그림자가 달아났다

  [ 다시 도전 · 250만골드 ]
  [ 나가기 ]
```

재도전 대가는 **그 구역 보스 골드 보상의 절반**에서 시작해 **재도전마다 2배**다.
골드로 한 이유는 후반에 남아도는 자원이라 쓸 데가 하나 더 생기고, 2배 누진이라
무한 재도전이 스스로 막히기 때문이다.

누진 카운터는 **구역을 나가거나 보스를 잡으면 0**으로 돌아간다.
상점 강화석([GoldShop])과 같은 방식이라 규칙이 하나로 통일된다.

「나가기」는 지금처럼 잡몹 진행을 지운다 — 대가를 안 냈으니까.

**승리**

```
     회랑 끝의 그림자를 잡았다
   💰 500만   💎 120   🪨 25

  [ 이 구역 더 돌기 ]
  [ 다음 구역으로 ]
```

「더 돌기」는 그 구역에 남아 잡몹부터 다시(재료 파밍), 「다음 구역으로」는 바로 진입.

두 팝업 다 화면 상태다. `bossFailed`·`zoneCleared` 플래그가 이미 있으므로 그것을
팝업으로 승격시키고, 재도전 대가만 도메인(`HuntRetry`)으로 새로 만든다.

### 3. 특수강화 — 별 10개, 별도 화면

강화 화면에서 떼어 내 기록 메뉴 옆에 자기 화면을 준다. 메인이 그만큼 짧아진다.

별 상한을 5에서 **10**으로 올린다. 다만 `ATTACK_PER_STAR = 0.14` 를 그대로 두면
공격력이 2.4배가 되어 **보스 문턱이 통째로 무너진다** — `BossTempoTest` 가 잡아 둔
"권장 +2에서 잡힌다" 곡선을 별로 우회하게 된다.

그래서 **별당 배수를 낮추고 뒤로 갈수록 덜 오르게** 한다. 별 10개의 총 배수가
지금 별 5개(1.7배)와 비슷해지도록 잡고, 정확한 값은 `BossTempoTest` 와
`BalanceSimulationTest` 가 통과하는 선에서 확정한다. 감으로 정하지 않는다.

성공률 곡선도 10단까지 늘린다. 뒤로 갈수록 낮아지되 0이 되지는 않는다.

## 작업 순서

작은 것부터. 각 단계가 끝나면 설치 가능한 게임이 된다.

| | 내용 | 왜 이 순서인가 |
|---|---|---|
| 1 | 확률 세 가지 (`ForgeOdds`) | 가장 작고 다른 것을 건드리지 않는다 |
| 2 | 사냥 결과 팝업 + 재도전 대가 | UI 중심, 도메인은 `HuntRetry` 하나 |
| 3 | 특수강화 별도 화면 + 별 10개 | 밸런스가 걸려 있어 마지막. 시뮬레이션으로 값 확정 |

## 테스트

- `ForgeOddsTest` — 세 값의 합이 1, 구간 경계, 아이템 반영
- `HuntRetryTest` — 첫 대가·2배 누진·리셋 시점
- `StarForceTest` — 별 10단 상한, 성공률 곡선이 단조 감소
- `BossTempoTest`·`BalanceSimulationTest` — 별 배수를 바꾼 뒤에도 통과해야 한다

## 하지 않는 것

- 사냥 자동 반복(오토) — 손맛을 깎는다
- 별로 파괴 확률을 낮추는 것 — 특수강화는 강화와 별개 계층으로 유지한다
