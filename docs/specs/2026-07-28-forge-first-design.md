# v1.7 「강화가 주인공」 — 설계

2026-07-28

## 문제

이 게임의 이름은 검 **강화** 게임인데, 실제로 하는 일은 사냥이다.

강화 한 번은 1초다. 그런데 그 한 번에 드는 것이

- 골드 (사냥에서)
- 재료 검 2~3자루 (사냥 드롭 또는 상점)
- 강화석 3~26개 (사냥·보스·분해)

이고 전부 사냥에서만 나온다. **준비 시간이 강화 시간의 백 배**다.
그래서 플레이어가 체감하는 주 활동은 사냥이고, 강화는 그 사이에 잠깐 누르는 것이 됐다.

후반이 특히 심하다. 강화석 요구가 `3 + (목표 - 16)` 으로 계속 늘어 +38 이면 한 번에 26개,
상한이 40개다. 그 구역 보스가 24개를 주므로 **보스 하나에 강화 한 번**이다.

여기에 골드는 반대로 남아돈다. 수입은 초원 잡몹 14골드에서 끝의 문 1.4억골드까지
천만 배가 되는데 상점 가격은 처음 그대로(방지권 800, 축복서 1,200, 검 100)라
후반에는 사실상 공짜다. 실제로 발목을 잡는 것은 골드가 아니라 재료다.

## 목표

**준비 시간을 줄인다. 위험은 그대로 둔다.**

파괴·하락의 긴장은 이 게임의 핵심이므로 건드리지 않는다. 줄이는 것은
"한 번 굴리기 위해 사냥터에서 보내야 하는 시간" 뿐이다.

### 못 박는 값

> **구역 하나를 완주하면(잡몹 12마리 + 보스 1) 그 단계 강화를 최소 5번 굴릴 재료가 나온다.**

`BossTempoTest` 가 5초 보스전을 지키는 것과 같은 방식으로, `ForgeTempoTest` 가 이 값을 지킨다.
이 값이 깨지면 다시 사냥 게임으로 돌아간 것이다.

## 설계

### 1. 재료 공급을 늘린다

| | 지금 | 바꿈 |
|---|---|---|
| 잡몹 강화석 확률 | 5% | **15%** |
| 보스 강화석 | 3~24개 | **2배** |
| 자리비움 강화석 | 시간당 1개 | **시간당 3개** |

잡몹 확률이 가장 크게 체감된다 — 12마리를 잡으면 기대값이 0.6개에서 1.8개가 된다.

### 2. 요구량 증가를 완만하게

```
지금:  target < 21 → 3 + (target - 16)
       target >= 21 → (8 + (target - 20)) 상한 40
바꿈:  target < 21 → 3 + (target - 16) / 2
       target >= 21 → (5 + (target - 20) / 2) 상한 15
```

+38 기준 26개 → **14개**. 상한 40 → **15**.

재료 검 요구(0/1/2/3자루)는 그대로 둔다. 자루 수는 애초에 완만하고,
보관함 관리가 곧 조합의 재미와 이어져 있다.

### 3. 골드로 재료를 산다

골드가 남아도는데 재료가 모자란 상태이므로, 둘을 잇는다.
**골드로 사는 편이 사냥보다 손해면 안 된다** — 그러면 다시 사냥을 강요하는 설계다.

가격 뼈대(승인된 안 C):

```
가격 = (지금 강화 비용 × 배수) × 1.18^(이 구간에서 산 개수)
```

- 강화석 배수 0.8, 재료 검 배수 0.5
- **최고 단계가 오르면 누진 카운터가 0으로 리셋된다** — 한 단계 올릴 때마다
  값이 되돌아오므로 골드가 계속 쓸 데를 얻는다
- 리셋은 한 곳에서만 일어난다(강화 성공으로 최고 단계 갱신 시)

최고 +20 기준: 첫 개 128,000(잡몹 1.5마리), 다섯째 249,000, 열째 597,000.
초반 몇 개는 확실히 살 만하고, 몰아 사려 하면 사냥이 낫다.

세이브에 붙는 필드(전부 기본값이 있어 옛 세이브 무손실):

| 필드 | 뜻 |
|---|---|
| `stonesBought` | 이 구간에서 산 강화석 수 |
| `swordsBought` | 이 구간에서 산 재료 검 수 |
| `priceBandLevel` | 카운터를 리셋한 기준 최고 단계 |
| `upgrades` | 영구 업그레이드 레벨(id → 단계) |

### 4. 아이템 값을 단계에 연동

```
가격 = max(지금 가격, 강화 비용 × 배수)
```

방지권 ×5, 축복서 ×8, 행운부적 ×12. 초반 값은 그대로 남고(하한),
후반에만 오른다. "이번엔 방지권 살까"가 실제 고민이 된다.

### 5. 대장간 — 영구 업그레이드

성공률·파괴 확률·보스 시간은 **팔지 않는다**. 그것을 돈으로 사면 이 게임의 긴장이
돈으로 지워진다(자동강화를 뺀 것과 같은 이유). 파는 것은 모으기·벌이뿐이다.

| 업그레이드 | 단계당 | 최대 |
|---|---|---|
| 가방 확장 | +4칸 | 5단계 (24 → 44) |
| 사냥 골드 | +10% | 5단계 |
| 조각 획득 | +10% | 5단계 |
| 강화석 드롭 | +2%p | 5단계 (15% → 25%) |
| 자리비움 상한 | +2시간 | 5단계 (8 → 18시간) |

가격은 `강화 비용 × 20 × 3^단계`. 한 단계 올릴 때마다 세 배가 되어
전부 최대까지 올리는 데 오래 걸린다.

### 6. 수상한 상자 — 도박

가격 `강화 비용 × 6`. 열면 하나가 나온다.

| 결과 | 확률 |
|---|---|
| 강화석 다발 (요구량의 2배) | 40% |
| 조각 다발 | 25% |
| 재료 검 3자루 | 20% |
| 펫 알 | 10% |
| 꽝 (조각 조금) | 5% |

기대값은 같은 값의 재료를 그냥 사는 것과 비슷하게 잡는다 — 도박이 정답이 되면
안 되고, 늘 손해여도 열 이유가 없다.

### 7. 화면

**상점을 탭 넷으로.**

| 탭 | 내용 |
|---|---|
| 검 | 계열 선택 · 손에 들기 · 가방에 넣기 · 판매 |
| 아이템 | 방지권 · 축복서 · 행운부적 · 수상한 상자 |
| 재료 | 강화석 구매(누진, 다음 가격 표시) |
| 대장간 | 영구 업그레이드 5종 |

재료 탭은 다음 가격과 함께 **왜 오르고 언제 풀리는지**를 한 줄로 알린다.
설명이 없으면 값이 오르는 것이 그냥 짜증으로 남는다.

**강화 화면 상단에 지갑 줄을 올린다.** 지금은 검 그림 아래에 있어 화면이 짧으면
스크롤해야 보인다. 하위 화면 다섯 곳에는 이미 붙어 있는데 정작 메인이 빠져 있었다.

## 테스트

- `ForgeTempoTest` — 전 구역에서 "완주 1회 = 강화 5회 이상" 확인
- `GoldShopTest` — 누진·리셋·하한, 최고 단계가 오르면 값이 되돌아오는지
- `UpgradesTest` — 단계 상한, 가격 증가, 효과 값
- `MysteryBoxTest` — 확률 합 1.0, 난수 경계값별 결과
- `BalanceSimulationTest` — 재료 조달 모델을 새 공급/요구로 갱신
- 기존 `ForgeCostTest` 의 요구량 기대값 갱신

## 하지 않는 것

- 성공률·파괴 확률·보스 제한시간을 파는 것
- 사냥 수입 곡선 조정(강화 비용과 맞춰 둔 균형이 깨진다)
- 골드 리디노미네이션(표기는 이미 억·조로 짧게 쓰고 있다)
