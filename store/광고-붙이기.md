# 광고 붙이기 — 애드몹에서 무엇을 만들고 어디에 넣나

코드는 이미 다 되어 있다. **지금 들어 있는 ID 는 구글이 공개한 시험용**이라
가짜 광고만 나오고 수익이 잡히지 않는다. 아래 두 곳만 진짜 값으로 바꾸면 된다.

## 1. 애드몹에서 만들 것 (사람이 해야 하는 일)

https://admob.google.com 에서 구글 계정으로 들어간다.

### ① 애드몹 계정

처음이면 계정을 만든다. 나라·시간대·결제 통화를 고르는데 **나중에 못 바꾼다.**

### ② 앱 등록

`앱` → `앱 추가` →

| 물어보는 것 | 답 |
|---|---|
| 플랫폼 | Android |
| 스토어에 등록되어 있나요? | **예** — 이미 콘솔에 올라가 있으면 검색해서 고른다 |
| 앱 이름 | 검 강화 / Sword Forge (`com.geomgang.game`) |

등록하면 **앱 ID** 를 준다. 생김새: `ca-app-pub-0000000000000000~1111111111`
(물결표 `~` 가 들어간다)

### ③ 광고 단위 만들기

만든 앱 안에서 `광고 단위` → `광고 단위 추가` → **배너** 를 고른다.

| 물어보는 것 | 답 |
|---|---|
| 광고 형식 | **배너** |
| 광고 단위 이름 | `강화화면 하단 배너` (아무 이름이나 된다) |

만들면 **광고 단위 ID** 를 준다. 생김새:
`ca-app-pub-0000000000000000/2222222222` (빗금 `/` 가 들어간다)

> 앱 ID 는 물결표, 광고 단위 ID 는 빗금이다. 둘을 바꿔 넣으면 앱이 켜지자마자 죽는다.

### ④ 결제 정보

`지급` 에서 주소와 계좌를 넣는다. 안 넣으면 광고는 나오지만 돈을 못 받는다.
주소 확인용 우편물(PIN)이 오는 데 2~4주 걸리니 미리 해 두는 편이 낫다.

### ⑤ 앱-ads.txt (나중에 해도 된다)

애드몹이 `app-ads.txt` 를 올리라고 알려 주면, 콘솔의 웹사이트 칸에 적은 주소
(`https://yongminlee2.github.io/legal/`)의 맨 위에 그 파일을 두면 된다.
안 해도 광고는 나오지만, 해 두면 단가가 오른다.

## 2. 받은 ID 를 넣을 곳 (두 군데뿐)

### 앱 ID → 매니페스트

`app/src/main/AndroidManifest.xml`

```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="여기에 ca-app-pub-...~... 를 넣는다" />
```

### 광고 단위 ID → AdConfig.kt

`app/src/main/java/com/geomgang/game/ads/AdConfig.kt`

```kotlin
private const val RELEASE_BANNER = TEST_BANNER   // ← 여기를 "ca-app-pub-.../..." 로
```

바꾼 뒤 릴리스를 다시 빌드한다.

```bash
./gradlew :app:bundleRelease :app:assembleRelease
```

## 3. 코드가 이미 해 두는 것

- **디버그 빌드는 언제나 시험용 광고**다. 내 폰에서 내 광고를 누르면 애드몹이
  부정 클릭으로 보고 계정을 막는데, 그 사고를 구조적으로 막아 둔 것이다.
- **유럽 동의 창**(UMP)을 앱을 열 때 띄운다. 구글이 만든 창이라 우리가 문구를
  열네 나라 말로 옮길 것이 없다. 동의가 필요 없는 지역에서는 그냥 넘어간다.
- 동의를 받기 전이나 광고가 안 들어왔을 때는 **배너 자리를 아예 만들지 않는다.**
  빈 회색 띠가 남으면 게임이 망가져 보인다.
- **사냥터와 무한 회랑에는 배너를 띄우지 않는다.** 화면을 쉬지 않고 두드리는
  곳이라 잘못 눌러 광고로 튕겨 나간다.
- 광고 등급을 **청소년(T)** 까지로 묶었다. 13세 이상 앱에 맞춘 것이다.
- 게임을 내려 두면 배너도 멈춘다.

## 4. 올리기 전 확인

- [ ] 매니페스트의 앱 ID 가 `3940256099942544` 로 시작하지 **않는다**
- [ ] `AdConfig.kt` 의 `RELEASE_BANNER` 가 `TEST_BANNER` 가 **아니다**
- [ ] 콘솔 **데이터 보안**에서 「기기 또는 기타 ID」 수집·공유를 체크했다
- [ ] 콘솔 **광고 포함 여부**를 「예」로 바꿨다
- [ ] `privacy.html` 을 push 했고 주소가 열린다

## 5. 나중에 보상형 광고를 붙일 때

지금은 배너 하나뿐이다. 보상형(광고 보고 보상 두 배)을 붙인다면 자리 잡기
좋은 곳은 **자리를 비운 사이 쌓인 보상을 받는 순간**이다. 강화 성공률이나
파괴 복구에 붙이면 게임의 균형이 무너지므로 피한다.

새 버튼 문구가 생기면 열세 언어 사전에도 같은 키를 넣어야 한다
(`tools/i18n/README.md` 참고). 배너는 문구가 없어 그 일이 없었다.
