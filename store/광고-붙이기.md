# 광고 붙이기 — 애드몹에서 무엇을 만들고 어디에 넣나

**진짜 ID 는 이미 다 들어가 있다.** 아래는 그 값이 무엇이고 어디 있는지,
그리고 나중에 바꿀 때 어디를 손대는지에 대한 기록이다.

| 무엇 | ID |
|---|---|
| 앱 | `ca-app-pub-6583185616347720~5090723269` |
| 배너 | `ca-app-pub-6583185616347720/8354733748` |
| 전면 | `ca-app-pub-6583185616347720/7041652070` |
| 보상형 | `ca-app-pub-6583185616347720/4180608455` |

디버그 빌드는 이 값을 **쓰지 않는다.** 언제나 구글 시험용 광고로 간다.

## 1. 애드몹에서 만들 것 (사람이 해야 하는 일)

https://admob.google.com 에서 구글 계정으로 들어간다.

### ① 애드몹 계정

처음이면 계정을 만든다. 나라·시간대·결제 통화를 고르는데 **나중에 못 바꾼다.**

### ② 앱 등록

`앱` → `앱 추가` →

| 물어보는 것 | 답 |
|---|---|
| 플랫폼 | Android |
| 스토어에 등록되어 있나요? | **예** — 이미 콘솔에 올라가 있으면 검색해서 고른다 |
| 앱 이름 | 검 강화 / Sword Forge (`com.geomgang.game`) |

등록하면 **앱 ID** 를 준다. 생김새: `ca-app-pub-0000000000000000~1111111111`
(물결표 `~` 가 들어간다)

### ③ 광고 단위 만들기 — 세 개

`광고 단위` → `광고 단위 추가` 에서 형식을 골라 만든다. 이름은 아무거나 된다.

| 형식 | 쓰는 곳 |
|---|---|
| 배너 | 대장간 화면 맨 아래 띠 |
| 전면 | 사냥터·무한 회랑에서 나올 때 |
| 보상형 | 자리비움 보상을 두 배로 받을 때 |

만들면 **광고 단위 ID** 를 준다. 생김새:
`ca-app-pub-0000000000000000/2222222222` (빗금 `/` 가 들어간다)

> 앱 ID 는 물결표, 광고 단위 ID 는 빗금이다. 둘을 바꿔 넣으면 앱이 켜지자마자 죽는다.

### ④ 결제 정보

`지급` 에서 주소와 계좌를 넣는다. 안 넣으면 광고는 나오지만 돈을 못 받는다.
주소 확인용 우편물(PIN)이 오는 데 2~4주 걸리니 미리 해 두는 편이 낫다.

### ⑤ 유럽 동의 메시지 (GDPR)

`개인정보 보호 및 메시지` → `유럽 규정` → 메시지 만들기 → 이 앱을 고르고 게시.
**안 만들면 유럽 이용자에게 동의 창이 안 뜨고 광고가 제한된다.** 앱 로그에
`no form(s) configured for the input app ID` 가 찍히면 이것이 빠진 것이다.
코드는 이미 준비되어 있어 앱을 다시 올릴 필요는 없다.

### ⑥ 앱-ads.txt (나중에 해도 된다)

애드몹이 `app-ads.txt` 를 올리라고 알려 주면, 콘솔의 웹사이트 칸에 적은 주소
(`https://yongminlee2.github.io/legal/`)의 맨 위에 그 파일을 두면 된다.
안 해도 광고는 나오지만, 해 두면 단가가 오른다.

## 2. 받은 ID 를 넣을 곳 (두 군데뿐)

### 앱 ID → 매니페스트

`app/src/main/AndroidManifest.xml`

```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="여기에 ca-app-pub-...~... 를 넣는다" />
```

### 광고 단위 ID → AdConfig.kt

`app/src/main/java/com/geomgang/game/ads/AdConfig.kt` 의 `LIVE_` 로 시작하는
상수 셋이다.

```kotlin
private const val LIVE_BANNER = "ca-app-pub-.../..."
private const val LIVE_INTERSTITIAL = "ca-app-pub-.../..."
private const val LIVE_REWARDED = "ca-app-pub-.../..."
```

바꾼 뒤 릴리스를 다시 빌드한다.

```bash
./gradlew :app:bundleRelease :app:assembleRelease
```

## 3. 어디에 어떻게 뜨나

### 배너 — 대장간 화면 아래

- **사냥터와 무한 회랑에는 안 뜬다.** 화면을 쉬지 않고 두드리는 곳이라
  잘못 눌러 광고로 튕겨 나간다.
- 광고가 실제로 들어오기 전에는 **자리를 아예 만들지 않는다.** 빈 회색 띠가
  남으면 게임이 망가져 보인다.
- 게임을 내려 두면 배너도 멈춘다.

### 전면 — 사냥터·무한 회랑에서 나올 때

**얼마나 자주 뜨는지가 전부다.** 나올 때마다 띄우면 사냥을 안 가게 된다.
두 가지로 묶어 두었다 (`ads/FullScreenAds.kt`).

- 앱을 켠 뒤 **3분** 안에는 안 뜬다 — 켜자마자 광고를 맞는 것이 가장 나쁜 첫인상
- 한 번 뜬 뒤 **4분** 동안은 다시 안 뜬다

광고가 아직 안 받아졌으면 **그냥 넘어간다.** 광고를 기다리느라 화면 전환이
멈추면 게임이 느린 것처럼 느껴진다.

뒤로 가기·나가기·포기 어느 길로 나오든 걸리도록 **화면 전환 자체**를 본다.
나가는 길목마다 코드를 심으면 새 길이 생겼을 때 빠뜨린다.

### 보상형 — 자리비움 보상 두 배

자리를 비운 사이 쌓인 보상 창에 「광고 보고 두 배로」 단추가 붙는다.

- **광고를 끝까지 봐야** 준다. 중간에 닫으면 아무 일도 없다
- 한 보상에 **한 번만** 준다
- 받으면 창의 숫자가 그 자리에서 두 배로 바뀐다 — 골드만 슬쩍 늘리면
  두 배를 받았는지 알 수 없다
- **띄울 광고가 없으면 단추 자체가 없다.** 눌러도 안 되는 단추보다 낫다

강화 성공률이나 파괴 복구에는 붙이지 않았다. **게임의 균형을 광고로 살 수
있게 되는 순간** 강화 게임이 아니게 된다.

### 공통

- **디버그 빌드는 언제나 시험용 광고**다. 내 폰에서 내 광고를 누르면 애드몹이
  부정 클릭으로 보고 계정을 막는데, 그 사고를 구조적으로 막아 둔 것이다.
- **유럽 동의 창**(UMP)을 앱을 열 때 띄운다. 구글이 만든 창이라 우리가 문구를
  열네 나라 말로 옮길 것이 없다. 동의가 필요 없는 지역에서는 그냥 넘어간다.
- 광고 등급을 **청소년(T)** 까지로 묶었다. 13세 이상 앱에 맞춘 것이다.

## 5. 광고를 더 붙이거나 자리를 옮길 때

**새 문구가 생기면 열두 사전에 같은 키를 넣어야 한다.** 키 집합이 어긋나면
`LocalizationCatalogTest` 가 빌드를 막는다. 「광고 보고 두 배로」를 넣을 때도
열두 파일을 함께 고쳤다 (`tools/i18n/README.md` 참고).

문장은 **통째로** 키에 넣는다. 「광고」와 「두 배로」를 따로 두면 조각 이어
붙이기로 흘러 어순이 뒤집힌다.
