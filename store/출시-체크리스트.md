## 2. 서명 키

**삐약푸쉬·왁뿌볼·끝말잇기와 같은 업로드 키**를 쓴다.

- 키 파일 `upload.jks` (별칭 `wordchain`), 비밀번호는 `keystore.properties`
- 둘 다 `.gitignore` 에 있어 깃에 올라가지 않는다
- 원본 백업: `C:\workAndroid\_서명키_백업\`
- 인증서 SHA-1 `D7:9A:58:0B:56:B2:34:E3:6F:A4:18:0E:B5:90:2A:EF:DF:B7:68:1F`

AAB 안에서 `META-INF/WORDCHAI.RSA` 가 보이면 이 키로 서명된 것이다.

> 이 키를 잃어버리면 같은 패키지명으로 다시는 업데이트를 올릴 수 없다.

## 4. 콘솔에서 답할 것

- **카테고리** — 게임 › 롤플레잉
- **광고 포함** — 아니요
- **인앱 구매** — 없음
- **데이터 보안** — 수집·공유 **없음**. 인터넷 권한이 없어 기기 밖으로 보낼
  방법 자체가 없고, `allowBackup="false"` 라 구글 자동 백업도 안 된다.
- **권한** — `VIBRATE` 하나. 강화 결과를 손끝으로 알리는 데만 쓴다.
- **콘텐츠 등급 설문** — 폭력 묘사 없음(픽셀 몬스터를 탭해 넘어뜨리는 정도),
  선정성·도박·약물 없음, 사용자끼리의 대화 기능 없음, 외부 링크 없음.

## 6. 스크린샷

언어마다 여섯 장. 1080×2340 세로.
폴더 이름은 **콘솔에서 고르는 언어 코드**와 맞춰 두었다.

중국어는 콘솔에 세 칸(简体·繁體·香港)인데 앱 사전은 둘이다 — 번체 하나로
대만과 홍콩을 함께 쓴다. 그래서 `zh-TW` 와 `zh-HK` 스크린샷은 같은 그림이다.

1. `01-none` 강화 화면 — 용검 +30, 성공·유지·하락·파괴 확률
2. `02-hunt` 사냥터 — 24구역 목록과 공격력
3. `03-gaunt` 무한 회랑 — 층·확정 보상·몬스터
4. `04-craft` 조합소 — 조합식과 숨은 조합 힌트
5. `05-codex` 도감 — 계열별 단계 그림
6. `06-pets` 펫 — 잠긴 칸과 얻은 펫

플레이 콘솔은 언어마다 **최소 두 장, 최대 여덟 장**을 받는다.
언어를 다 채우기 버거우면 한국어·영어만 넣어도 등록은 된다.

1. 매니페스트에 `INTERNET` 권한 추가
2. `legal/swordforge/privacy.html` 7번(광고와 결제)을 실제대로 고치고 push
3. 콘솔의 **데이터 보안**과 **광고 포함 여부** 신고를 갱신
4. 그다음에 새 빌드를 올린다
