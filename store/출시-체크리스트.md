## 2. 서명 키

**삐약푸쉬·왁뿌볼·끝말잇기와 같은 업로드 키**를 쓴다.

- 키 파일 `upload.jks` (별칭 `wordchain`), 비밀번호는 `keystore.properties`
- 둘 다 `.gitignore` 에 있어 깃에 올라가지 않는다
- 원본 백업: `C:\workAndroid\_서명키_백업\`
- 인증서 SHA-1 `D7:9A:58:0B:56:B2:34:E3:6F:A4:18:0E:B5:90:2A:EF:DF:B7:68:1F`

AAB 안에서 `META-INF/WORDCHAI.RSA` 가 보이면 이 키로 서명된 것이다.

> 이 키를 잃어버리면 같은 패키지명으로 다시는 업데이트를 올릴 수 없다.

## 4. 콘솔에서 답할 것

- **카테고리** — 게임 › 롤플레잉
- **광고 포함** — **예.** 애드몹 배너·전면·보상형 셋을 쓴다.
- **인앱 구매** — 없음
- **데이터 보안** — 우리가 모으는 것은 없지만 **광고 SDK 가 광고 ID 를 읽는다.**
  신고할 때는 아래대로 체크한다.
  - 수집: **기기 또는 기타 ID → 기기 또는 기타 ID** (광고 목적, 필수 아님)
  - 공유: 같은 항목을 **구글(애드몹)** 과 공유
  - 전송 중 암호화됨: 예 / 삭제 요청 가능: 예(기기 설정에서 광고 ID 초기화)
  - 게임 세이브는 여전히 기기 안에만 있고 `allowBackup="false"` 다.
- **권한** — `VIBRATE`, `INTERNET`, `ACCESS_NETWORK_STATE`, 그리고 광고 SDK 가
  스스로 넣는 `AD_ID`·`WAKE_LOCK`·`FOREGROUND_SERVICE`. 전부 런타임 동의가
  필요 없어 이용자에게 창이 뜨지 않는다.
- **콘텐츠 등급 설문** — 폭력 묘사 없음(픽셀 몬스터를 탭해 넘어뜨리는 정도),
  선정성·도박·약물 없음, 사용자끼리의 대화 기능 없음.
  **광고가 있으므로 「광고 표시」에 예**라고 답한다.

## 6. 스크린샷

언어마다 여섯 장. 1080×2340 세로.
폴더 이름은 **콘솔에서 고르는 언어 코드**와 맞춰 두었다.

중국어는 콘솔에 세 칸(简体·繁體·香港)인데 앱 사전은 둘이다 — 번체 하나로
대만과 홍콩을 함께 쓴다. 그래서 `zh-TW` 와 `zh-HK` 스크린샷은 같은 그림이다.

1. `01-none` 강화 화면 — 용검 +30, 성공·유지·하락·파괴 확률
2. `02-hunt` 사냥터 — 24구역 목록과 공격력
3. `03-gaunt` 무한 회랑 — 층·확정 보상·몬스터
4. `04-craft` 조합소 — 조합식과 숨은 조합 힌트
5. `05-codex` 도감 — 계열별 단계 그림
6. `06-pets` 펫 — 잠긴 칸과 얻은 펫

플레이 콘솔은 언어마다 **최소 두 장, 최대 여덟 장**을 받는다.
언어를 다 채우기 버거우면 한국어·영어만 넣어도 등록은 된다.

## 8. 광고

v1.1.0 부터 **애드몹 광고**가 붙는다. 배너는 대장간 화면 아래, 전면은
사냥터·회랑에서 나올 때, 보상형은 자리비움 보상을 두 배로 받을 때다.
자세한 것은 `광고-붙이기.md` 에 있다.

올리기 전에 반드시 확인한다.

1. `app/src/main/AndroidManifest.xml` 의 `APPLICATION_ID` 가 진짜 앱 ID 인가
2. `app/src/main/java/com/geomgang/game/ads/AdConfig.kt` 의 `LIVE_` 상수 셋이
   진짜 광고 단위 ID 인가
3. `privacy.html` 과 콘솔의 **데이터 보안·광고 포함 여부** 신고가 빌드와 맞는가

나중에 인앱 결제를 붙일 때도 순서는 같다 — **방침을 먼저 고치고 빌드를 올린다.**
