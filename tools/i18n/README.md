# 번역 도구

`app/src/main/assets/i18n/*.json` 을 만들고 검사하는 스크립트다.
전부 파이썬 3이고 인자는 프로젝트 루트 하나뿐이다.

```bash
python tools/i18n/cjk_audit.py .
```

## 왜 필요한가

번역은 **한국어 원문이 곧 키**다. 화면이 그리기 직전에
`GameTranslator.translate()` 가 세 단계로 찾는다.

1. `exact[원문]` — 문장이 통째로 사전에 있으면 그대로 쓴다
2. `byPattern` — 숫자만 `{}` 로 바꾼 꼴을 찾는다
3. **조각 이어 붙이기** — 위 둘이 없으면 긴 조각부터 갈아 끼운다

3번으로 흘러가면 뜻이 깨진다. 「가시 대검」이 스페인어에서
「Grieta Gran espada」가 되고, 한자권에서는 낱말 사이에 빈칸이 남아
「亀裂 大剣」이 된다. 그래서 **화면에서 이어 붙여 만드는 문장은 나올 수 있는
짝을 미리 다 키로 넣어 둔다.** 아래 생성기가 그 일을 한다.

## 생성기 — 순서대로 돌린다

키를 새로 만들거나 계열·구역·단계 이름을 바꾸면 이 순서로 전부 다시 돌린다.
뒤엣것이 앞엣것의 결과를 읽으므로 순서가 중요하다.

| 순서 | 파일 | 무엇을 만드나 |
|---|---|---|
| 1 | `names_gen.py` | 계열 이름 + 수식어 85개로 조합 검 이름 95개 |
| 2 | `stages.py` | 단계 이름 + 계열 이름으로 만들어지는 이름 196개 |
| 3 | `recipes.py` | 조합식 문구 (`마검+20 + 성검+20 → 용검+1` 같은 줄) |
| 4 | `forgecard.py` | 계열 조합 칸의 제목과 부제 |
| 5 | `essences.py` | 구역 24곳의 정수 요구 한 줄 |

```bash
for f in names_gen stages recipes forgecard essences; do
  python tools/i18n/$f.py .
done
```

## 검사기 — 고친 뒤 전부 0이어야 한다

| 파일 | 무엇을 잡나 |
|---|---|
| `cjk_audit.py` | 한자·가나 사이의 빈칸. 일본어·중국어는 낱말을 띄어 쓰지 않는다 |
| `slot_audit.py` | `{}` 가 낱말에 달라붙은 곳 (`{}Die Entschädigung`) |
| `dup_audit.py` | 서로 다른 검이 같은 이름으로 나오는 곳 |
| `seg_audit.py` | 값이 다른 값 두 개 이상을 이어 붙인 꼴 |
| `roman_audit.py` | 옮기지 않고 한국어 소리만 적어 둔 곳 (`Gyun-yeol`) |
| `caps_audit.py` | 문장 가운데에 큰 글자가 섞인 곳 |

`roman_audit` 과 `caps_audit` 은 걸러 낸 목록을 눈으로 봐야 한다 — 정상인 것도
걸린다. 나머지 넷은 **0이 아니면 버그**다.

`LocalizationCatalogTest` 가 12개 사전의 키 집합이 같은지, 값에 한글이 남지
않는지, 낱말 사전(강화=Enhance 등)이 지켜지는지를 빌드에서 확인한다.

## 손으로 고칠 때 지키는 것

- **문장을 통째로 키에 넣는다.** 조각으로 나누면 어순이 뒤집힌다
- **셈낱말을 조심한다.** 개·마리·종·자루·회·초·장은 기계 번역이 거의 틀린다
  (개→dog, 마리→Marie, 종→bell, 자루→sack, 초→second<sup>둘째</sup>)
- **숫자 단위는 번역이 아니라 코드가 만든다** — `GameLanguage.myriadUnits`
  (한국어 만·억·조 / 일본어 万·億·兆 / 중국어 간체 万·亿·兆 / 번체 萬·億·兆)
- **말투는 반말로 통일한다** — 독일어 du, 프랑스어 tu, 러시아어 ты
- 코드에서 새 문장을 이어 붙였다면 **그 짝도 사전에 넣는다**

## 화면에서 이어 붙이는 곳

여기를 고치면 사전도 같이 손봐야 한다.

| 어디 | 무엇 |
|---|---|
| `SwordNames.nameFor` | 단계 이름 + 계열 이름 (`stages.py` 가 담당) |
| `CraftScreen` 정수 요구 줄 | 구역 이름 + 정수 (`essences.py` 가 담당) |
| `CraftScreen` 조합 칸 | 계열 이름 (`forgecard.py` 가 담당) |
| `HelpTopics` | 여러 줄을 이어 붙인 본문 — **완성 문장을 통째로 키에 넣는다** |
| `Progress.basicFamilyHint` | 해금 조건 문장 |
